### メモを受けて確かめた事実（Claude Code）

- **課題 8：プレビューの縦横比が崩れる。** 正しい比は 2:3（0.667）。配布物を開いて、プレビューの表示の大きさを測った。

  | 画面 | スタート画面 | 作成画面 |
  | --- | --- | --- |
  | 800×800 | 418×750（0.557） | 237×643（0.369）。横スクロールも出る |
  | 1024×768 | 418×718（0.582） | 261×626（0.417） |
  | 1280×800 | 418×750（0.557） | 438×658（0.666） |
  | 1600×900 | 418×850（0.492） | 505×758（0.666） |
  | 1920×1080 | 418×1030（0.406） | 625×938（0.666） |

  作成画面は幅 1024 以下で細くなる。**スタート画面は、どの大きさでも縦に伸びている**（Phase 1-C-D で入れた不具合）。
- **課題 2：左腕。** 仮素材には、右腕の「ポケット」の絵はあるが、左腕の「ポケット」の絵がない。左腕を「ポケット」にしても、重なりの順が変わるだけで、見た目はほとんど変わらない。
- **課題 3・4：編集対象。** 小分類（前髪 → 後ろ髪）や大分類を切り替えても、右ペインの編集対象は前に選んだパーツのまま残る。

### 判断と、直したこと（2026-10-05）

判断（原文）：「下部があるせいで混乱している。英語なのも原因の一つ。視覚的に分かりやすい。操作しやすいを優先してください。」

| メモ | 直したこと |
| --- | --- |
| 課題 1・9：PNG の保存が分からない。導線が分かりにくい | 下の帯（英語）をなくした。作成画面の右上に「画像を書き出す →」を目立つ色で置いた。「保存」は「キャラクターを保存」にして、画像の保存と区別した |
| 課題 2：スタート画面のプレビューが右に寄りすぎ | 入力欄とプレビューを隣り合わせにして、中央に置いた |
| 課題 2：左腕が機能していない | 仮素材に、左腕の「ポケット」の絵を足した（素体、シャツ、T シャツ） |
| 課題 3・4：分類を変えても前のパーツの色が変わる | 分類を切り替えたら、その分類で装備中のパーツを編集対象にするようにした |
| 課題 6：詳細設定は常時開いていてよい | 最初から開くようにした（閉じられる。閉じたことは覚える）。内部の ID は、その中の「内部情報」を開いたときだけ出る |
| 課題 8：狭くすると体が細くなる | プレビューが常に 2:3 を保つようにした。1024〜1920 の 4 つの幅で、3 つの画面とも 2:3 であることを自動で確かめている |

直していないもの：

- 課題 5（ポーズ・向きのパターンが足りない）：向きの追加は素材の量が大きいため、Phase 2 以降へ送る。
- 通知の置き場所：既定を「右ペインの上」にしたが、4 案の比較は未実施。比較用の切り替えは残っている。
- 課題 0 の、回線を切った状態での確認：未実施。
